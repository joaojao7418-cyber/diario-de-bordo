Nesta aula aprendi que o versionamento de arquivos serve para registrar cada mudança feita em um projeto, de modo que nunca precisemos guardar cópias como "final_v2" ou "final_v3_corrigido". Entendi que o Git é a ferramenta que faz esse registro no próprio computador, e que cada commit funciona como um ponto de salvamento com mensagem, autor e data. Também vi que o GitHub hospeda esses repositórios online e facilita o trabalho em equipe com recursos como Pull Requests e revisão de código. Por fim, percebi que a branch principal (main) é a versão oficial do projeto, e que alterações feitas com revisão evitam quebrar o trabalho dos colegas.
